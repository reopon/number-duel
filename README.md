# Number Duel

A quick browser game: you pick a secret number for the CPU to hunt down, then
race against the CPU to guess its hidden number first. Every guess gets a
"higher" / "lower" hint. Whoever finds the other's number in fewer guesses
wins the duel.

## Play

Just open `index.html` in a browser, or serve the folder with any static
file server, e.g.:

```sh
npx serve .
```

No build step or dependencies required.
